# 实现桌宠休息和翻译双模式功能

## 功能需求

1. **双模式切换**：
   - 休息模式：桌宠不会读取剪贴板，支持与用户聊天
   - 翻译模式：桌宠只进行翻译，不聊天
   - 模式切换通过界面按钮实现

2. **状态显示**：
   - 在桌宠正右边添加一个漫画风格的牌子
   - 牌子大小为桌宠的1/4
   - 休息模式显示"休息中"
   - 翻译模式显示"翻译中"
   - 牌子有轻微摇晃的动画效果
   - 点击牌子有翻转动画

3. **AI交互**：
   - 休息模式：使用可自定义的AI提示词，支持聊天
   - 翻译模式：使用固定的翻译提示词，只进行翻译

4. **设置功能**：
   - 修改设置对话框，添加休息模式AI提示词设置
   - 翻译提示词固定，不可修改

5. **剪贴板监控**：
   - 休息模式：关闭剪贴板监控，不自动翻译
   - 翻译模式：开启剪贴板监控，自动翻译

## 技术实现

1. **添加状态切换按钮**：
   - 在桌宠界面添加模式切换按钮
   - 按钮显示当前模式，点击切换

2. **添加状态牌子**：
   - 创建一个QLabel作为牌子，显示当前状态
   - 使用漫画风格的样式，白板黑字
   - 添加轻微摇晃的动画效果
   - 添加点击翻转动画

3. **修改AI交互逻辑**：
   - 添加休息模式的AI聊天功能
   - 修改translate方法，根据当前模式执行不同逻辑

4. **修改设置对话框**：
   - 添加休息模式提示词设置区域
   - 固定翻译提示词，不可修改

5. **修改剪贴板监控**：
   - 根据当前模式控制剪贴板监控的启用状态

6. **添加配置文件**：
   - 保存休息模式AI提示词
   - 保存当前模式设置

## 预期效果

- 程序启动时默认进入休息模式
- 桌宠右边显示"休息中"的漫画风格牌子，有轻微摇晃动画
- 点击模式切换按钮或牌子切换到翻译模式
- 翻译模式下显示"翻译中"的牌子，自动监控剪贴板进行翻译
- 休息模式下关闭剪贴板监控，支持与桌宠聊天
- 设置对话框支持修改休息模式的AI提示词，打造用户喜欢的形象
